# Easy Shop 🛍️

Easy Shop is a modern and feature-rich E-Commerce mobile application built using **Flutter**. It is designed to provide a smooth, responsive shopping experience for customers while offering robust product management and administrative views.

## 🚀 Key Features
* **User-Friendly Interface:** Modern UI with customizable themes and intuitive navigation.
* **Product Management:** Dynamic views for browsing, filtering, and managing products.
* **Shopping Experience:** Complete customer flow including product details, cart management, and seamless interaction.
* **Admin & Client Views:** Tailored screens to handle both user shopping needs and administrative control.
